## Notes for Stage 7 / 8

- The instance record stays `TERMINATED`, so a Stage 7 cost table can cite
  actual lifecycle state rather than an inference.
- `terraform.tfvars` was preserved, so a re-deploy costs one `tofu apply`; the
  destroyed host's `.env`, master key and vault are gone by design — a fresh
  deployment regenerates them (that is what the Stage 3 playbook documents).
- The GitHub repository is still unpublished; publishing is Stage 8.

## Limitations

- "Zero billable resources" is established from the OCI API responses above and
  the fact that the boot volume is destroyed with the instance. Billing reports
  lag; a cost dashboard may still show the terminated instance's history for the
  current period.
- No foreign-network probe was run against the old IP; the closed-port checks
  were made from the operator machine.
