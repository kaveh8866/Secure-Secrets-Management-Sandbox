## Defect found by the live run

`tests/smoke.sh` hardcoded `python`, which exists on the Windows development
host but **not** on Ubuntu 24.04 (only `python3`). On the instance this produced
three false failures — two `json_field` parses returned empty strings and the
oversized-body fixture was never written, so the `413` assertion saw an empty
body and `400`. The script now resolves `python3`/`python` once (overridable via
`PYTHON=…`) and names the interpreter explicitly. It also fails fast with a clear
message when neither exists.

The first verification pass also caught an error in the drill script itself (a
JSON payload sent without the `{"value": …}` envelope, correctly rejected with
`400`), which is recorded here rather than quietly fixed in the transcript.

## Cost

`VM.Standard.A1.Flex` at 1 OCPU / 1 GB is within the Always Free allowance; the
50 GB boot volume and the VCN components are free-tier eligible. The instance is
**left running** — teardown is Stage 6 and happens only on explicit request.

## Limitations

- The service speaks plain HTTP on port 8200. Ingress is restricted to the
  operator `/32` for both 22 and 8200, so the network boundary is the security
  list, not TLS. Do not widen `api_allowed_cidr` while this remains true.
- Reachability was verified from the allowed workstation and from the host
  itself; it was **not** probed from a foreign network. The `/32` restriction is
  confirmed from the applied security list, not from a failed external attempt.
- One node, one vault file, no replication: an instance loss loses the data
  unless the vault file and master key are backed up separately.
